⚓ About the Map

Project background, data sources, and methodology behind the Door County Shipwrecks interactive webmap.

What This Map Is

This interactive web map compiles and visualizes 220 recorded shipwrecks This interactive web map compiles are visualizes all 220 shipwrecks in Door County, WI, from the years 1850-1951. Each wreck is plotted at it's respective location and includes information about the specific wreck; vessel name, type, year built, cause of wreck, length of ship, and lives lost. There are many different types of audiences that will benefit from this webmap, including maratime and Great Lakes historians, as well as tourists, and students. No prior knowledge is needed while using this web map.

How to Use the Map

  • ⚓ Ship Markers — Anchor icons mark each wreck location. Click any anchor to open a popup showing vessel name, type, year built, build location, crash date, cause of loss, ship length, water depth, and lives lost.
  • 🚢 Proportional Ships — Ship icons scaled by vessel length in feet. Three size classes: Small (<100 ft), Medium (100–200 ft), and Large (200+ ft). Larger icons represent longer vessels. Click for full details.
  • 🔢 Cluster Layer — When zoomed out, nearby wrecks are grouped into numbered clusters. The number shows how many wrecks are contained within it. Zoom in to split clusters apart and reveal individual wreck locations. Clusters are color-coded: blue (small), orange (medium), red (large concentrations).
  • 💥 Wreck Type Layer — Color-coded circle markers showing the cause of each vessel's loss: 🔴 Burned/Fire, 🔵 Foundered/Sunk, 🟠 Stranded/Grounded, 🟣 Abandoned, 🟢 Wrecked, 🟤 Collision, ⚫ Other/Unknown. Click any marker for casualty-specific details.
  • 🌊 Basemap Toggle — Switch between ESRI Ocean (bathymetric depth shading, default) and ESRI Topo (terrain and place names) using the layer control panel in the top-right corner of the map.
  • 🔍 Vessel Search — Type a vessel name (e.g. "Adriatic" or "Tempest") in the search bar in the top-right corner to zoom directly to that wreck. The anchor icon will glow yellow and the popup will open automatically.
  • 🌐 Home Button — Resets the map back to the default Door County view after zooming or panning.
  • 🗺️ Mini Map — A small overview map in the bottom-left corner providing regional geographic context. Click the arrow to collapse or expand it.
  • 📏 Scale Bar — Located in the bottom-right corner, showing real-world distance at the current zoom level in both metric and imperial units.

Methods

  • Reproject: Shipwreck data was reprojected to WGS84 in ArcGIS Pro to ensure compatibility with Leaflet.js, which requires geographic coordinates.
  • Clip: The dataset was clipped to the Door County boundary, removing wrecks outside the study area and reducing file size.
  • Clean attribute table: Unneeded fields were removed from the attribute table. Key fields retained: vessel name, type, construction year, build location, casualty date, casualty type, hull material, propulsion, length, water depth, and lives lost.
  • Field cleanup in JavaScript: Decimal lengths were rounded using Math.round(). Casualty dates stored in mixed formats (MM/DD/YYYY and year-only) were parsed using a regex year extractor.
  • Export format: Data exported from ArcGIS as GeoJSON, then wrapped as a JavaScript variable (ship_wrecks) in shipwrck_edit.js for reliable browser delivery without requiring a server fetch call.

Limitations & Credits

Limitations
Data Gaps in Popups Some vessel records have null or blank values for fields such as build location, ship length, and year built. This reflects incomplete historical recordkeeping and cannot be resolved with the available data.
Bathymetric Basemap Zoom Limit The ESRI Ocean basemap has a maximum native zoom level. Zooming beyond that threshold produces "No Data" tiles. The ESRI Topo basemap is available as an alternative for close-up views.
No Mobile-Optimized Layout The sidebar and map layout are designed for desktop viewing. On smaller screens the sidebar compresses and may require scrolling to access all legend and layer controls.
